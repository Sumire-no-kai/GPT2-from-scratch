# GPT-2 从零实现：前置知识大纲

这份大纲用于明确每个阶段需要了解的知识，不要求全部学完再开始。项目使用 PyTorch 提供张量运算、自动求导和设备支持，模型结构与训练流程由自己实现。

## 1. Python 基础

**学习时机：开始前要能熟练使用。**

- 函数、参数、返回值、类与继承。
- 列表、字典、集合、切片、循环和推导式。
- 模块导入、文件读写、虚拟环境与依赖安装。
- 阅读异常堆栈，用断点检查变量。

**掌握标准：**能独立写一个读取文本、统计字符、建立字符编号表的小程序。

## 2. 线性代数与张量

**学习时机：开始前理解基本概念，操作细节边写边学。**

- 标量、向量、矩阵和高维张量。
- 张量形状、维度与轴；矩阵乘法的维度规则。
- 转置、逐元素运算、求和、均值和广播。
- 常用维度：批量 `B`、序列长度 `T`、特征维度 `C`、词表大小 `V`。

**掌握标准：**能解释 `(B, T, C) @ (C, V)` 为什么得到 `(B, T, V)`，并跟踪计算过程中各个张量的形状。

## 3. 概率与微积分

**学习时机：先掌握直觉，推导可以逐步补。**

- 概率分布、条件概率、采样、期望。
- 对数、softmax、负对数似然与交叉熵。
- 导数、偏导数、梯度、链式法则。
- 梯度下降为何能用于减小损失，以及学习率的作用。

**掌握标准：**知道模型给正确答案的概率越低，交叉熵损失越大；理解梯度如何指导参数更新。

## 4. PyTorch 基础

**学习时机：在字符级 bigram 热身阶段学习。**

- Tensor 的创建、索引、`dtype`、`device`。
- `reshape`、`view`、`transpose`、`permute` 与内存连续性。
- `nn.Module`、参数注册、`forward`。
- `Embedding`、`Linear`、交叉熵。
- 计算图、`backward()`、梯度累积、`zero_grad()`、优化器更新。
- `train()` / `eval()` 与禁用梯度的区别。
- 模型和数据如何放到同一个设备：`cpu`、`mps` 或 `cuda`。

**掌握标准：**自己完成一次“前向计算 → 损失 → 反向传播 → 参数更新”，并解释每一步的作用。

## 5. 语言模型与数据处理

**学习时机：从 bigram 到 tokenizer 阶段学习。**

- 字符、字节、token、词表之间的区别。
- 自回归建模：根据前面的 token 预测下一个 token。
- 输入与目标右移一位，以及训练批次的构造。
- 训练集 / 验证集划分，以及数据泄漏。
- BPE 的合并规则、编码与解码、GPT-2 的 byte-level BPE。

**掌握标准：**能从一段文本构造训练样本，解释每个位置的预测目标，并检查编码、解码的对应关系。

## 6. Transformer 与 GPT-2

**学习时机：实现模型时重点学习。**

- Token embedding 与位置 embedding。
- 注意力中的 Q、K、V，缩放点积与 softmax 的计算方向。
- 因果遮罩为什么能阻止模型看到未来。
- 多头注意力的拆分、合并及张量形状变化。
- MLP、GELU、残差连接、LayerNorm。
- GPT-2 的 Pre-LayerNorm 结构、输出 logits 与权重共享。

**掌握标准：**能画出一个 Transformer block，标出每一步的输入输出形状，并解释每个位置能够使用哪些信息。

## 7. 训练与正确性验证

**学习时机：基本训练流程在 bigram 阶段练习，进阶内容在模型能运行后补齐。**

- 学习率、AdamW、权重衰减、学习率调度。
- 过拟合、验证损失、梯度裁剪、梯度累积。
- Checkpoint 保存与恢复。
- 浮点误差、随机种子、数值比较的容差。
- 加载参考权重，比较中间输出和最终 logits。

**掌握标准：**能区分“代码能运行”“loss 在下降”和“实现符合 GPT-2”这三种不同的验证结果。小规模训练验证训练流程，参考权重与输出对齐验证模型实现。

## 8. 生成与性能

**学习时机：基础模型正确后，按需要学习。**

- Greedy decoding、temperature、top-k、top-p。
- KV cache 为什么能减少重复计算。
- 显存占用与 batch size、序列长度的关系。
- 混合精度、训练吞吐量与性能测量。

**掌握标准：**能解释采样参数如何影响生成结果，测量训练速度和显存占用，再决定是否需要优化或更换硬件。

## 建议的起点

先具备 Python 基础、张量形状、概率和梯度的基本直觉，就可以从字符级 bigram 开始，把 PyTorch 和训练流程在一个小模型上串起来，再进入 tokenizer、注意力与 GPT-2。

此时无需先掌握 CUDA 内核开发、分布式训练或从头实现自动求导引擎。完整阶段安排见[开发日志](dev-log.md)，自己的理解、推导和实验记录写在[学习笔记](../notes/)。
