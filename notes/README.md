# 学习笔记

这里存放我学习 GPT-2 过程中写的笔记，会发布到个人网站 [xiaonan.dev](https://xiaonan.dev) 的 `/blog`（开发日志）栏目，也可能同步到公众号。

网站上"从零实现 GPT-2"的现有内容只是草稿，之后会用这里的笔记全部替换。所以以这里为准，网站跟着改。网站源码在 `Sumire-no-kai/Personal_Website`。

## 分工

- **我来写**：主要内容，包括自己的理解、推导、踩过的坑和实验结果。
- **AI 来润色**：纠正技术错误，理顺表达和结构，但保留我的语气和观点。拿不准的技术点会标出来问我，不会直接改掉原意。

## 写作约定

- 一篇笔记一个文件，命名为 `NN-slug.md`。`NN` 按学习顺序编号，`slug` 是英文短名，也用作网站上的网址，例如 `00-intro.md`、`01-bigram.md`。
- 文件开头用 frontmatter 记录元信息：

  ```yaml
  ---
  title: 从 bigram 开始：最简单的语言模型
  summary: 一两句话的摘要，用在网站列表和分享卡片上
  date: 2026-10-01
  tags: [GPT-2, PyTorch]
  status: draft  # draft 草稿 → polished 已润色 → published 已发布
  ---
  ```

- 笔记用中文写。网站现在支持中、英、日三种语言，同步到网站时英文和日文版本怎么处理，到时再定。
- 图片放在 `notes/images/`，用相对路径引用。
- 引用代码时，注明它在仓库中的文件路径。
- 阶段说明在需要时放入实际代码，并就地解释影响理解的语法；标明当前实现与待修改建议，避免把笔记扩展成基础 Python 教程。
- 发布到公众号时，外部链接无法点击，需要转成文末脚注。mdnice 之类的排版工具可以自动转换。
